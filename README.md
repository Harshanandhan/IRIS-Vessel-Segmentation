"I designed an Iris Vessel Segmentation system to accurately detect blood vessels in iris images for biometric applications. Using a U-Net model with an EfficientNetB3 backbone, I leveraged Artificial Intelligence and Machine Learning to segment vessels from preprocessed 544x544 images. The dataset, sourced from Google Drive, included training and testing images with ground truth masks. Custom loss functions like Dice Loss and metrics such as Matthews Correlation ensured robust performance. Data augmentation (flipping, rotation) enhanced model generalization. The system employs a sliding window approach for large-scale predictions. This project ties into Cyber Security by improving biometric authentication reliability. It also has potential for Blockchain integration to securely store segmented data. Built with TensorFlow, Keras, and Python, it showcases my technical expertise. The work demonstrates practical applications in secure identity verification."
